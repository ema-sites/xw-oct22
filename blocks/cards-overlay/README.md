# cards-overlay

Custom **cards** block. Purpose: Two-up grid of large product cards with a full-bleed photo, dark overlay and eyebrow, heading, text and CTA overlaid.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card; cell 1 background photo, cell 2 rich text with eyebrow paragraph, heading, description and CTA link.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

## Reuse guidance

Use for product/feature promo cards with text on top of a photo. For simple label-only linked tiles use cards-tiles.
