# cards-tiles

Custom **cards** block. Purpose: Edge-to-edge row of tall image tiles, each fully linked with a short label over the image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile; cell 1 tile image, cell 2 the label authored as a link (the whole tile becomes clickable).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

## Reuse guidance

Use for audience/segment navigation tiles (image + single label link). Author the label as a link; the whole tile becomes clickable. For cards with eyebrow, description and CTA use cards-overlay.
