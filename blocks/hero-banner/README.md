# hero-banner

Custom **hero** block. Purpose: Full-width photo background banner with heading, short text and a CTA, used for promotional bands.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 background image; row 2 rich text with heading, short text and CTA link.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

## Reuse guidance

Use for image-backed promo banners anywhere on the page. For a video background use hero-video.
