# hero-video

Custom **hero** block. Purpose: Full-width band with an autoplaying, muted, looping background video (Vimeo, YouTube or MP4) behind a headline or statement.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 optional poster/fallback image; row 2 rich text with heading or statement, optional CTA, and the background video URL (Vimeo, YouTube or .mp4) as a plain link, which is removed from the text and rendered as autoplaying muted looping background.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

## Reuse guidance

Use for heroes or statement bands whose background is a video. Author the video URL as a plain link in the text; it is removed from the text and rendered as background media. An optional image acts as poster/fallback. For a photo background, use hero-banner.
